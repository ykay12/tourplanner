23.04.
im application.properties haben wir folgende Zeile:
    spring.jpa.hibernate.ddl-auto=update
Diese ermöglicht es uns, dass durch das Einfügen von Daten die Datenbank verändert wird.
Wichtig! Das macht nur während der Entwicklung Sinn! -> Für die Finale Abgabe müssen wir es auf das:
    spring.jpa.hibernate.ddl-auto=none
ändern! (Siehe Foliensatz: "akarta Persistence API (JPA) with Spring Data JPA" Folie: 9)

Wie starten wir überhaupt?
1.) Docker-Desktop starten
2.) dann an der Stelle in der Ordnerstruktur wo das docker-compose.yml liegt den Befehl
      docker compose up -d
    durchführen

Wenn DB Änderungen und Docker läuft:
docker compose down
docker compose up --build

Repository Design Pattern
Repository ist das einzige das "Datenbank-Sprache" -> spricht.
    Dadurch wird die DB einfacher austauschbar.

Noch schöner: Repository + UnitOfWork
-> Mehrere Repositorys führen gemeinsam eine Transaktion durch.
-> z.B.: Ich speichere die Tour + Ihre Logs (eigentlich zwei Repositorys damit verbunden)


Wir sollen jedenfalls ein Repo pro Aggregation machen.
