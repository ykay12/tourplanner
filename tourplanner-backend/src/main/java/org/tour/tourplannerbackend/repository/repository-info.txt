23.04.
im application.properties haben wir folgende Zeile:
    spring.jpa.hibernate.ddl-auto=update
Diese ermöglicht es uns, dass durch das Einfügen von Daten die Datenbank verändert wird.
Wichtig! Das macht nur während der Entwicklung Sinn! -> Für die Finale Abgabe müssen wir es auf das:
    spring.jpa.hibernate.ddl-auto=none
ändern! (Siehe Foliensatz: "akarta Persistence API (JPA) with Spring Data JPA" Folie: 9)
